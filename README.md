# Food Delivery Business Analysis | Power BI

## Project Overview

This project presents a comprehensive Power BI business analytics report developed to analyze food delivery operations and business performance.

The report explores customer behavior, restaurant performance, order trends, revenue, delivery operations, and advanced business insights.

## Report Pages

### 1. Executive Overview

Provides an overview of:

- Total Revenue
- Total Orders
- Average Order Value
- Average Delivery Time
- Order Status
- Revenue Trends
- Order Trends
- Top Restaurants

### 2. Customer Analytics

Analyzes:

- Total Customers
- New vs Repeat Customers
- Repeat Customer Percentage
- Orders per Customer
- Customer Type
- Customer Signup Trends
- Order Trends

### 3. Restaurant Performance

Analyzes:

- Restaurant Revenue
- Restaurant Orders
- Cuisine-wise Orders
- Average Restaurant Rating
- Top Restaurants
- Cost Bucket Analysis
- Online vs Offline Orders
- Average Votes

### 4. Delivery & Operations

Analyzes:

- Delivery Status
- Delivered Orders
- Delayed Orders
- Cancelled Orders
- Average Delivery Time
- Late Delivery Percentage
- City-wise Delivery Time
- Cancellation by City

### 5. Advanced Insights

Includes:

- Average Delivery Time
- Orders
- Average Order Value
- Revenue
- KPI Trends
- Delivery Time Analysis

### 6. Restaurant Details

Provides restaurant-level analysis including:

- Revenue
- Orders
- Average Rating
- Customer Type
- Delivery Status
- Order Trends
- Revenue Trends
